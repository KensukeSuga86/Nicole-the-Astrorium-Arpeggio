Nicole the Astrorium 簡易使い方マニュアル

対象：Nicole the Astrorium Arpeggio / GitHub Pages v1.1.4

1. 起動

GitHub Pagesで公開したURLをGoogle Chromeで開きます。

トップページからPresenter（操作画面）が起動します。

観客向けの星空を別画面に表示したい場合は、画面上部の 「観客画面を開く」 を押します。

Chromeにポップアップをブロックされた場合は、このサイトのポップアップを許可してください。

2. 基本的な使い方

観測地点と日時を設定する

左上の 「観測条件」 で設定します。

  • 日時：表示したい日時を入力
  • 現在時刻：今の時刻へ移動
  • 地名検索：都市名などから観測地点を選択
  • 現在地：端末の位置情報を利用
  • 緯度・経度：数値で直接入力可能
  • お気に入り：よく使う地点を保存・呼び出し

設定後は 「この条件を適用」 を押します。

月齢カレンダーでは、日付を選んで日の出・日の入り・月の出入り・天文薄明などを確認できます。

3. 星空を動かす

画面下部の日時操作から時間を進めたり戻したりできます。

  • −1h / +1h：1時間移動
  • −10m / +10m：10分移動
  • ▶：時間を連続再生
  • 再生速度：×1 ～ ×6000
  • 現在時刻：現在へ戻る
  • 日の出 / 日の入り / 月の出 / 月の入り：その時刻へ直接移動

主な初期ショートカット：

  • Space：再生 / 停止
  • Shift + Space：逆再生
  • N：現在時刻
  • A / S / D / F / G：再生速度切替

ショートカットは画面上部の 「ショートカット一覧」 から変更できます。

4. 見る方向を変える

右下の 「カメラ」 で星空の向きを設定します。

  • 方位：0°＝北、90°＝東、180°＝南、270°＝西
  • 仰角：地平線から見上げる角度
  • 水平視野角：画面に映る空の広さ

60° / 90° / 120° ボタンから代表的な視野角へすぐ切り替えられます。

5. 星座・天体を探す

左側の 「星座・天体検索」 に名称を入力します。

例：

  • オリオン
  • M31
  • 木星
  • ベガ

検索結果から対象を選ぶと、該当天体を確認できます。

6. 表示するものを切り替える

中央の表示設定パネルから、星空に重ねる要素をON / OFFできます。

代表例：

  • 恒星
  • 惑星
  • 太陽・月
  • 星座名
  • 星座線
  • 星座絵
  • 天の川
  • 肉眼・双眼鏡天体
  • 流星群
  • オーロラ
  • グリッド類

用途に応じて必要な表示だけをONにすると、解説しやすくなります。

7. PresenterとProjector

Presenter は解説者用の操作画面、Projector は観客に見せる星空画面です。

Presenterで変更した、

  • 日時
  • 観測地点
  • カメラ方向
  • 表示レイヤー
  • 星座表示
  • メディア
  • ペン描画

などはProjectorへ反映されます。

プロジェクターや外部ディスプレイを使う場合は、Projectorウインドウを観客用画面へ移動し、全画面表示すると便利です。

8. 画像や動画を投影する

画面上部の 「メディアライブラリ」 を開きます。

「画像・映像を追加」 を押す

使用する画像または動画を選ぶ

ライブラリから投影したいメディアを選ぶ

星空へ戻すときは 「投影を終了」

読み込んだメディアは、このブラウザ内のNicoleローカルライブラリに保存されます。

9. ペンで書き込む

「ペンツール」 を使うと、Projector上に解説用の線や書き込みを表示できます。

星の並びを示したり、注目してほしい場所を囲んだりする用途に向いています。

10. 解説台本を使う

「解説台本」 には春・夏・秋・冬のタブがあります。

自作タブでは、現在の星空状態を順番に記録してオリジナルの解説台本を作れます。

  • 台本作成開始
  • 現在の状態を1ステップとして記録
  • JSONとして書き出し
  • JSONから読込

といった操作ができます。

11. 場所を移動する演出

画面下部の 「場所を移動」 では、現在地点から別の緯度・経度へ連続的に移動できます。

移動中は、その地点から見える星空へリアルタイムに変化します。

「北海道からオーストラリアへ移動して南天を見る」といった解説演出にも使えます。

12. よく使う機能

投影表示設定

上部の 「投影表示設定」 から、文字・星の見え方などProjector側の表示を調整できます。

レイアウトを初期化

パネル配置が崩れた場合は、

設定 → レイアウトを初期化

を使用します。

星カタログを取り込む

細かい恒星表示を追加したい場合は、

設定 → 星カタログを取り込む

から対応ファイルを読み込めます。

13. 保存されるデータについて

お気に入り地点、メディア、表示設定、ショートカットなど一部のデータはブラウザ内に保存されます。

そのため、

  • 別のChromeプロフィール
  • 別のブラウザ
  • 別の端末

では自動的に共有されません。

ブラウザのサイトデータを削除すると、Nicole内に保存したローカルデータも消える場合があります。

14. 困ったとき

観客画面が開かない

Chromeのポップアップブロックを解除してください。

現在地が取得できない

地名検索、主要都市、または緯度経度の直接入力を使ってください。

表示がおかしくなった

まずページを再読み込みし、それでも直らない場合は 設定 → レイアウトを初期化 を試してください。

GitHub Pages版で更新が反映されない

PWAやService Workerのキャッシュが残っている場合があります。Chromeでページを再読み込みし、必要ならサイトデータ・キャッシュを更新してください。

最初に覚える5つ

観測条件 で日時と場所を決める

カメラ で見る方向を決める

表示パネルで 星座・天体・天の川などをON/OFF する

観客画面を開く でProjectorを表示する

下部の時間操作で空を動かす

この5つだけで、基本的なプラネタリウム解説を始められます。
